# 伦理、隐私与数据声明

## 1. 数据性质

本研究使用一套真实生产级多智能体系统的运行日志，包括 Agent 消息、工具调用、任务状态、业务结果计数和文件元数据。数据来自一套内部估值表解析系统，源数据根目录在公开文档中以 `C:\path\to\valuation` 占位表示，研究期间只读访问。

公开仓库**不包含**原始数据库、估值表快照、结果 JSON、完整消息文本或产品映射。公开材料只包括脱敏聚合、论文、图表、分析代码和复现说明。

## 2. 人类受试者

不涉及人类受试者。全库只有 1 条人类消息（“现在还有哪些任务没有完成”，12 个字符），已在论文中脱敏引用。没有人类被观察、访谈或实验；没有个人画像、自动决策或高风险应用。

## 3. 隐私与脱敏

- 公开聚合不含产品名称、基金代码、产品路径、产品-specific 财务值或原始快照路径。
- 产品统一为 `Product NNN`；代码统一为 `PNNN`；机构/解析模块统一为 `module_NN`（变体 `module_NNx`）。
- 原始模块名与产品映射只保存在 `data/private/`（gitignore），公开文件不包含它们。
- 案例引用只保留 `message_id`、`session_id`、UTC 时间、Agent 角色和脱敏后的片段；不引用含产品名/代码的原文长句。
- `data/private/` 保存完整映射，已在 `.gitignore` 中排除；不提交、不公开。
- 仓库文件内容不包含 `.env`、API key、OpenCode password、数据库凭据、cookie 或个人邮箱；git 提交元数据中的作者邮箱由作者保留。
- `analysis/privacy_check.py` 在提交前扫描产品名/代码/密钥模式；pre-commit hook 强制执行。
- 公开仓库的完整 git 历史已清理源路径标识；`paper/paper.pdf` 等构建产物在清理后重新生成。

## 4. 用途限制

本研究用于理解多 Agent 协作与语言现象，不用于产品评价、财务决策、客户画像或自动决策。论文中的“成功/失败”指流程状态，不是财务正确性或投资建议。聚合数据不能用于重识别具体产品、客户或机构。

## 5. 风险

- **再识别风险**：即使脱敏，熟悉该系统的内部读者仍可能通过时间、job 结构或版本哈希推断产品。论文按内部研究报告的公开版本处理，不公开原始数据。
- **归因风险**：主会话历史缺口使“首现”不等于“绝对首现”；论文已标注。
- **误用风险**：行话密度可能被误用为“Agent 能力指标”；论文明确它是“难度/争议指标”。
- **模型风险**：单模型、单系统、8 天观察窗口；不能外推到所有多 Agent 系统。
- **标注风险**：词项审读由两个大语言模型实例完成，不是人类双标注；论文如实披露，未报告人类标注者间一致性。

## 6. 数据保留与开放科学

源数据由原系统保留；本研究不复制原始 Excel、结果 JSON 或完整消息文本到公开仓库。派生 parquet 在本地 `data/derived/`（gitignore）；公开聚合在 `data/aggregates/`；完整映射在 `data/private/`（gitignore）。

公开的论文、图表、聚合表、分析脚本和复现说明足以核对论文中的聚合数字，但不足以重建原始消息文本或业务数据。复现需要研究者自行取得只读源数据，并通过 `VALUATION_SRC` 指向本地根目录。
