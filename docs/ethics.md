# 伦理与数据声明

## 1. 数据性质

本研究使用一套内部生产系统的运行日志，包括 Agent 消息、工具调用、任务状态、业务结果计数和文件元数据。数据来自 `C:\path\to\valuation`，只读访问。

## 2. 人类受试者

不涉及人类受试者。全库只有 1 条人类消息（“现在还有哪些任务没有完成”，12 个字符），已在论文中脱敏引用。没有人类被观察、访谈或实验。

## 3. 隐私与脱敏

- 公开聚合不含产品名称、基金代码、产品路径、产品-specific 财务值。
- 产品统一为 `Product NNN`；代码统一为 `PNNN`。
- 案例引用只保留 message_id、session_id、UTC 时间、Agent 角色和脱敏后的片段；不引用含产品名的原文长句。
- `data/private/` 保存完整映射，已 gitignore；不提交、不公开。
- 不包含 `.env`、API key、OpenCode password、数据库凭据。
- `analysis/privacy_check.py` 在提交前扫描产品名/代码/密钥模式；pre-commit hook 强制执行。

## 4. 用途限制

本研究用于理解多 Agent 协作与语言现象，不用于产品评价、财务决策、客户画像或自动决策。论文中的“成功/失败”指流程状态，不是财务正确性或投资建议。

## 5. 风险

- **再识别风险**：即使脱敏，内部读者仍可能通过时间、job 结构、版本哈希推断产品。论文按内部研究报告处理，不公开原始数据。
- **归因风险**：主会话历史缺口使“首现”不等于“绝对首现”；论文已标注。
- **误用风险**：行话密度可能被误用为“Agent 能力指标”；论文明确它是“难度/争议指标”。
- **模型风险**：单模型、单系统、8 天；不能外推到所有多 Agent 系统。

## 6. 数据保留

源数据由原系统保留；本研究不复制原始 Excel、结果 JSON 或完整消息文本到公开仓库。派生 parquet 在本地 `data/derived/`（gitignore）；公开聚合在 `data/aggregates/`；完整映射在 `data/private/`（gitignore）。

## 7. 开放科学

论文、图表、聚合表、分析脚本和复现说明提交到本仓库；原始数据不公开。复现包足以核对论文中的聚合数字，但不足以重建原始消息文本。
