# 红队记录：可能的反驳与回应

## 反驳 1：`valution` 只是工具调用错误，不是“语言”

**回应**：本文不把 `valution` 当作自然语言词，而是当作工具语法层的词形。它满足词形的三个条件：可重复、可组合、可扩散；它还发生了语义漂白（absorbing subagent/job/product/empty schemas）。即使它是“错误”，它也是语言系统的一部分——错误词形同样会被上下文强化、被其他 Agent 模仿、消耗预算。把它排除，反而会漏掉最重要的病理机制。

## 反驳 2：`逐字`、`收口` 可能是模型的一般词汇，不是“涌现”

**回应**：我们区分“新造词”和“提示词之外的 convention”。`逐字` 可能来自模型的一般中文能力，但它在系统里获得了稳定的语用功能（要求逐字符证据、禁止转述），并且从 parser 扩散到四个 Agent。论文用“extralexical operational term”而不是“neologism”，正是为了避免过度主张。9 个与种子文本重叠的词也单独标注。

## 反驳 3：行话密度与 rounds 的相关只是“难任务说得更多”

**回应**：我们同意，并在正文明确说“行话密度是难度/争议指标，不是能力指标”。Poisson 回归控制派工 token 后系数仍为正（0.208，p=0.019），且负二项过度离散修正后仍显著（0.212，p=0.010，α=0.287）；但这不是因果。我们把它作为“标记”而非“原因”。

## 反驳 4：收敛结果可能是采样噪声

**回应**：我们用了 pooled null 和 5,000 次窗口 bootstrap CI；12 小时窗 main–reviewer p=0.012（q=0.072，边缘），24 小时窗 main–reviewer p=0.007（q=0.020）、main–watchdog p=0.002（q=0.014），后两者通过 FDR。main–parser 不显著，parser–reviewer 无显著趋势。本嗓口径下含 main 的 pair 仅 5 个窗口、全部不显著，我们据此把结论限定在全量口径，并明确 12h 的边缘性与检验力限制。

## 反驳 5：分类器 main F1 只有 0.332，说明“角色方言”不成立

**回应**：角色方言不需要“每个角色都可分”。我们的结论是“梯度”：Watchdog 高度可分（0.932），parser/reviewer 中度（0.651/0.698），main 是拼装体（0.332）。去 Watchdog 三分类 macro-F1=0.568、排序不变；本嗓口径下 main 的 639 条话语 F1=0.000——主 Agent 的可识别性几乎全部来自转述的子 Agent 语汇。这恰好说明主 Agent 的语域由子 Agent 词汇 + 调度词汇构成，而不是一个独立的纯语域。分类器的混淆矩阵本身就是证据。

## 反驳 6：主会话历史缺失 48.7%，首现归因不可靠

**回应**：我们承认，并把 child-first 称为“上界”。早主 Agent 的语言通过 756 条 parser 派工、676 条 reviewer 派工保留；这些派工是主 Agent 写的，能支持“主 Agent 早期用词”的分析。论文在 4.7 和 8.2 明确说明。

## 反驳 7：产品脱敏后，案例不可复核

**回应**：案例保留 message_id、session_id、UTC 时间、Agent 角色；内部读者可用源库复核。公开读者只能核对聚合数字和脱敏片段。这是内部研究数据的必要折中；`data/private/` 保存完整映射，但不公开。

## 反驳 8：结果数量不等于财务正确

**回应**：同意。本文的“成功”是流程完成/激活，不是财务审计。论文 8.6 明确说明；语言与财务正确性的关系需要另一项研究。

## 反驳 9：`valution` 2,271 次连续调用可能是 harness 重试，不是模型行为

**回应**：v1.1 已把间隔结构实测入聚合（`e6_summary.json`、`e6_burst_onsets.csv`）：2,271 次是 2,271 条独立 assistant 消息，每条一个 tool part；爆发内间隔中位数 0.93 秒，49 次 612.5–643.0 秒的停顿把序列切成 50 个爆发，停顿合计 8.46 小时（占 9.09 小时跨度的 93%）。更关键的是，49 次重新点火之前都有同一条 192 字符的 synthetic 空闲提醒（先于首调用中位 1.46 秒），即节奏由外部定时器起搏，而非 harness 对同一条消息的自动重试。schema 随时间变化（subagent → job → product → empty）也说明模型在生成不同意图；我们只把“连续 run”作为描述，不假设每一次都是独立理性决策。

## 反驳 10：`cost=0`，所以“2.49 亿 token”没有经济意义

**回应**：token 是协调带宽的代理，不是美元成本。我们明确说 `cost=0` 是 provider 未配置价格；token 仍能说明上下文占用和推理负担。不同 provider 的价格会改变“值不值得”的结论，但不改变“2,271 次无效调用”的事实。

## 反驳 11：事件级“督导—创新”关联可能是过度离散假象

**回应**：同意，且 v1.1 已验证：Poisson 回归中显著的 trial/validate/watchdog_main 系数（q=0.031），在负二项修正后全部不显著（α=1.77，p=0.007；q 均 ≥0.38）。论文 5.7 已把该关联降级为机制假说，只保留点估计方向；job 级行话—轮次关联则通过 NB 修正（p=0.010），两者区别对待。
